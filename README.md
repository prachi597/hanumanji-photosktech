<h1>🚩 Hanuman Ji Python Sketch</h1>
<p>A simple Python script to convert any Hanuman Ji image into detailed ASCII text art.</p>

<hr>

<h2>📋 Requirements</h2>
<p>This project requires Python and the <code>Pillow</code> (PIL) library.</p>
<p>Install Pillow using pip:</p>

<pre><code>pip install pillow</code></pre>
<pre><code>python -m pip install opencv-python numpy</code></pre>

<hr>

<h2>🚀 How to Run</h2>
<ol>
  <li>Clone or download this repository.</li>
  <li>Place your image file (e.g., <code>hanuman.jpg</code>) in the same folder as <code>hanuman.py</code>.</li>
  <li>Open <code>hanuman.py</code> and ensure the image filename matches your file at the bottom:<br>
      <code>image_to_ascii("hanuman.jpg", new_width=120)</code></li>
  <li>Run the script from your terminal:<br>
      <code>python hanuman.py</code></li>
  <li>The ASCII art will be printed in your terminal and saved to <code>hanuman_ascii_art.txt</code>.</li>
</ol>

<hr>

<h2>⚙️ Customization</h2>
<ul>
  <li><b>Image Width:</b> Adjust <code>new_width=120</code> to change the size of the ASCII art.</li>
  <li><b>Different Image:</b> Change <code>"hanuman.jpg"</code> to any other image path.</li>
</ul>
